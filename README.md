# نظم نوین جهان — The New World Order

بازی استراتژی کلان مرورگری، فارسی و راست‌چین، موبایل‌محور، از ۱ ژانویه ۱۹۴۶.
A Persian RTL mobile-first grand strategy browser game starting 1 January 1946.

**نسخه زنده:** https://kianodd.github.io/new-world-order/

## اجرا و توسعه (Development)

```bash
npm install
npm run dev     # توسعه محلی
npm test        # تست‌های موتور (Vitest)
npm run build   # بیلد تولیدی در dist/
```

## انتشار روی GitHub Pages (Deployment)

- مسیر پایه Vite روی `/new-world-order/` تنظیم شده است.
- ورک‌فلوی `.github/workflows/deploy.yml` با هر پوش به `main`، تست و بیلد می‌گیرد و روی GitHub Pages منتشر می‌کند.
- اسکریپت جایگزین `push.py` فایل‌های منبع را با Git Data API (سریالی، با PAT) آپلود می‌کند.

## معماری (Architecture)

- `src/engine/` — موتور شبیه‌سازی مستقل از React: `types.ts`، `data.ts` (داده تاریخی ۱۹۴۶)، `events.ts` (رویدادها)، `sim.ts` (تیک ماهانه قطعی با RNG بذردار، اقتصاد/جمعیت/سیاست/فناوری/دیپلماسی/جنگ/AI)، `rng.ts`
- `src/store.ts` — پل Zustand میان موتور و رابط
- `src/map/geo.ts` — مرزهای واقعی جهان از Natural Earth (`world-atlas`، مقیاس ۱۱۰متر، ۱۷۷ سرزمین) با پروجکشن Natural Earth (d3-geo)، نگاشت ISO به ۳۰ کشور موتور و نام فارسی سرزمین‌ها
- `src/components/MapView.tsx` — نقشه تعاملی PixiJS روی مرزهای واقعی (لمس، زوم دو انگشتی، دوبار لمس، برچسب فارسی در زوم بالا، حالت‌های نقشه)
- `src/App.tsx` — رابط فارسی RTL موبایل‌محور با ناوبری پایینی هشت‌تایی
- `src/save.ts` — ذخیره چنداسلاته IndexedDB + خروجی/ورودی JSON؛ تنظیمات در localStorage

## کنترل‌ها (Controls)

- انتخاب کشور از فهرست آغازین؛ روی نقشه روی کشور بزنید، با دو انگشت زوم و با کشیدن جابه‌جا شوید.
- کنترل زمان: توقف / عادی / سریع / بسیار سریع / ماه بعد. رویدادهای مهم (با تنظیم) بازی را متوقف می‌کنند.
- اقتصاد: مالیات و تجارت و رفاه را تنظیم و ساخت‌وساز کنید. سیاست: آموزش و سلامت و حقوق کار. دیپلماسی: ائتلاف و تحریم. ارتش: اعلان جنگ و صلح. فناوری: پژوهش با پیش‌نیاز.

## ذخیره (Saves)

ذخیره‌ها در IndexedDB مرورگر می‌مانند و پس از بارگذاری دوباره صفحه باقی می‌مانند. خروجی/ورودی JSON هم هست. نسخه ذخیره در فایل ثبت می‌شود.

## محدودیت‌های صادقانه (Known limitations)

- مرزهای نقشه از Natural Earth (مقیاس ۱۱۰متر) و **تقریبیِ مدرن** است، نه مرزهای دقیق ۱۹۴۶ و بدون استان؛ وضعیت سیاسی ۱۹۴۶ در داده‌های موتور اعمال شده است. هر ۱۷۷ سرزمین روی نقشه دیده می‌شود؛ ۳۰ کشور قابل‌بازی‌اند و بقیه با یادداشت وضعیت ۱۹۴۶ نمایش داده می‌شوند.
- جمعیت و GDP **برآورد تاریخی** (Maddison/UN) با برچسب اطمینان در داده‌ها.
- جنگ در سطح کشور و جبهه ساده‌شده است (بدون واحدهای تاکتیکی یا نقشه استان‌به‌استان).
- پرتره رهبران تصویری نیست؛ نام و سمت تاریخی واقعی آمده است.
- باندل JS بزرگ است (PixiJS + Recharts + d3-geo)؛ داده نقشه تنبل بارگذاری می‌شود اما اولین بارگذاری روی گوشی میان‌رده کندتر است.
- چیدمان ۳۹۰ پیکسل در کد بررسی شده؛ تأیید نهایی روی گوشی واقعی با کاربر است.

## گام‌های بعدی

استان‌ها و مرز تاریخی ۱۹۴۶، قابل‌بازی‌کردن کشورهای بیشتر، زنجیره تولید عمیق‌تر، انتخابات و احزاب، سازمان ملل و بحران‌های چندمرحله‌ای، بهینه‌سازی حجم باندل.
